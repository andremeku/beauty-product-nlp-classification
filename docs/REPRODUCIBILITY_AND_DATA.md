# Reproducibility and disclosure notes

## Notebook status

- `notebooks/hackathon_final_analysis.ipynb` is a **code-only archive** of the uploaded final notebook: cell outputs cleared, pip-install cells removed, and the input filename changed to `data/hackathon_dataset.csv`.
- `notebooks/hackathon_experiments.ipynb` is a similarly sanitized archive of the earlier workflow. The original developer's absolute Windows paths were replaced with a relative dataset conversion example.
- These original workflows are presented as **historical hackathon artifacts** rather than as independently verified, error-free production pipelines. Some CodeCarbon sections from the original notebook have environment-specific behavior.
- `notebooks/public_demo.ipynb` and `src/demo_pipeline.py` are separately prepared **synthetic-data examples**. Their model evaluations are not claims about original hackathon quality.

## Rights and publication

The user-provided source CSV and XLSX files were not packaged in this GitHub edition. No organizer-provided license or public redistribution permission has been supplied. Confirm permission before publishing those datasets, the competition's sensitive outputs, or any event materials. Respect collaborators' authorship.

## Performance claims

The original recorded outputs were cleared to avoid publishing derived event data and environment-identifying information. There is no claimed validated benchmark score in this public release. Use an authorized copy of the dataset to rerun the analysis when you have permission.
